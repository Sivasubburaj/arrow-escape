# Arrow Escape

A colorful arrow puzzle game. Tap an arrow to send it flying off the board, but only if nothing is in its way. Clear the board in the right order, with no slips, for 3 stars.

**Play:** https://sivasubburaj.github.io/arrow-escape/

On Android, open the link in Chrome and choose **Install app** (on the home screen or from the ⋮ menu). It then runs full screen and works offline.

## Features

- 150 levels from 3×3 to 9×8, each guaranteed solvable
- Free undo, hints, and a warning when the board can no longer be cleared
- 4 themes (Sunset, Ocean, Candy, Neon), sound effects and haptics
- Progress saved on the device

## Run locally

No build step. Serve the folder and open http://localhost:8123:

```bash
python -m http.server 8123
```
